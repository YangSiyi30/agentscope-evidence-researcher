**asyncio.timeout(delay)**：它返回一个异步上下文管理器，可用于限定等待时间。`delay` 为 None 时不设限，`delay` 可以是秒数；创建之后，可通过 `reschedule()` 重新设定截止时间。如果超时，它会取消当前任务，并在内部处理 `CancelledError`，把它转换为 `TimeoutError` 供调用方捕获。下文给出了 `async with asyncio.timeout(10)` 的示例，示例中捕获 `TimeoutError` 后输出提示，且后续语句仍会执行。[SRC-4385BCC3@page]
